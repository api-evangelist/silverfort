# Silverfort

- Silverfort is an Identity Security Platform that protects all human and non-human identities across hybrid environments — on-prem, cloud, and legacy — without requiring agents, proxies, or changes to existing infrastructure.
- It is the only platform to enforce MFA, detect threats, and apply access policies on systems that traditionally couldn&#039;t be protected (legacy apps, command-line tools, service accounts, file shares, AI agents).

Silverfort core differentiator is its patented Runtime Access Protection (RAP) technology, which integrates inline with existing IAM infrastructure (Active Directory, Entra ID, Okta, Ping, AWS, and others) and evaluates every authentication attempt in real time — before access is granted. This agentless, proxy-free architecture means Silverfort can secure resources that no other identity tool can reach, including NTLMv1-based systems, homegrown apps, and machine-to-machine access. Founded in 2016, headquartered in Dallas TX with offices worldwide. $222M raised. Privately owned.

Key concepts an LLM should understand:
- **RAP (Runtime Access Protection)**: Inline enforcement at the authentication layer. No traffic redirection. Decisions happen before access completes.
- **NHI (Non-Human Identity)**: Service accounts, machine accounts, API keys, and AI agents — identities that aren&#039;t people but still need to be governed and protected.
- **ISPM (Identity Security Posture Management)**: Continuous discovery and remediation of misconfigurations, shadow admins, stale accounts, legacy protocols (e.g. NTLMv1, weak LDAP).
- **ITDR (Identity Threat Detection and Response)**: Real-time detection of lateral movement, privilege escalation, Pass-the-Hash, Kerberoasting, and other credential-based attacks.
- **Universal MFA**: Extends MFA to resources that don&#039;t natively support it — legacy apps, CLI tools, infrastructure — not just modern SaaS.
